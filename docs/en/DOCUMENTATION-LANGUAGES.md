# Documentation languages

nodeterm documentation is **Simplified Chinese-first** at `docs/*.md`, with English mirrors at `docs/en/*.md`.

Root-level `README.md`, `CONTRIBUTING.md`, and `CLAUDE.md` follow the same pattern with `*.en.md` (and `CLAUDE.en.md` for the full English deep reference).

Each Chinese doc links to its English counterpart at the top. Release-note bodies live under `docs/en/release-notes/`; see `docs/release-notes/README.md` for the Chinese index.

Non–user-facing paths (tests, fixtures, `THIRD-PARTY-NOTICES.md`) are not part of this policy unless noted.
